# Source Serif 4

Self-hosted Latin WOFF2 files, regular and italic at weight 400, downloaded from Google Fonts on November 5, 2026. Source Serif is licensed under the SIL Open Font License 1.1; the accompanying `OFL.txt` retains the upstream notice and license.

Font metadata and download URLs were obtained from the Google Fonts CSS API for `Source Serif 4`, styles `0,400` and `1,400`. These assets are bundled locally and do not require visitors to connect to Google Fonts.
